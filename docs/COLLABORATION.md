# Team Collaboration Plan

The confirmed collaboration plan is two one-hour meetings each week, combining online and in-person sessions, with WeChat communication between meetings. This is a planned arrangement, not a claim that any meetings have already taken place. This confirmed cadence supersedes the earlier tentative Friday two-hour proposal. All five members participate in product decisions, clarification answers, document review, and approval. Run one shared AI-DLC workflow.
